Build notes

  • Design system: Two Create (warm canvas #f9f7f4, ink #0c0c0c, 1 px rules #e3e1dd). Dark theme uses its reversed canvas.
  • Type: PP Neue Montreal, Inter as the substitute, weight 400 only; hierarchy by size (111 / 66.6 / 44.4 / 33.3 / 22.2).
  • No filled buttons, no rounded corners, no shadows. Color lives only inside the images.
  • Assets: Codex kit (S1–S5, L1–L13, F1–F3) plus the blue link layer from the motion preview. Every image carries an "AI-generated" mark.
  • Motion: 0.7 s ease-in-out reveals from a visible state; one orchestrated moment (the station); everything stops with reduced motion.
  • Copy in English (NASA requirement). Eva guides, records and warns; never "diagnoses" or "treats".
  • Live page: Eva by WearMeds.
