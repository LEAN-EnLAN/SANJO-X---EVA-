# Eva by WearMeds

Team Sanjo-X · NASA Space Apps Challenge 2026 · Rosario · Challenge: *Create Health Monitoring Software for Astronauts on Space Missions*.

Eva is the assistant inside WearMeds wearables (chest band, large-screen wristband and a shared cabin station) for passengers on a commercial trip in space. Eva **guides, records and warns**: when someone cannot act, it guides the nearest passenger; when they can, it lights the right tool at the station; it warns of solar particle events using NASA DONKI and NOAA GOES data; and it records every step for Earth. It does not diagnose or treat.

- `landing/` public landing page · `wire/` annotated wireframe · `proto/` interactive prototype · `app/` Rust + htmx app (in progress).
- NASA data: Inspiration4 on NASA OSDR (OSD-575, OSD-569), DONKI.
