# Eva app wireframes

Vite + React + Tailwind v4 wireframes for the Eva app (passenger phone and crew dashboard), linted with @shadcn/lint. `npm run build` writes a single-file `dist/index.html` plus `dist/img/`.

## AI-generated images

Every image under `public/img/` (the 3D icons, Eva's mascot states and the wristband scenes) is AI-generated concept art made for team Sanjo-X (NASA Space Apps Challenge 2026, Rosario). The team wrote the prompts with Claude, and the images were generated with an OpenAI image model through Codex. They are illustrative and contain no NASA insignia or branding. This notice replaces on-screen labels: the wireframes show none.
